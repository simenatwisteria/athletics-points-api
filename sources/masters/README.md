# NFIF — Mangekamptabell for masters

**Mangler.** Lastes ned manuelt av Simen fra forbundet, så fasiten er den filen NFIF publiserer.

| Fil som trengs | Hvor | Brukes til |
|---|---|---|
| Mangekamptabell masters — menn (Excel) | friidrett.no → Arrangement → Arrangementshjelp → Poengtabeller | Primær fasit (tabell-lookup) for masters mangekamp |
| Mangekamptabell masters — kvinner (Excel) | Samme side | Samme |

Tabellene bygger på WMAs aldersfaktorer fra 2023 og brukes sammen med `sources/wma/` til kryssverifisering.

Når filene legges inn: filnavn uten mellomrom (f.eks. `masters-mangekamp-menn.xlsx`), og SHA-256 i
`sources/README.md` og `sources/SHA256SUMS`.
