# NFIF — tabeller for masters

Lastet ned 2026-09-26 fra https://www.friidrett.no/aktiviteter/masters/poengberegning/. Se tabellen i
`sources/README.md` for filnavn, URL og SHA-256.

- `nfif-masters-mangekamp-menn.xlsx` / `-kvinner.xlsm`: oppslagstabeller 1–1200 poeng per 5-årsklasse og øvelse,
  med egne ark for manuell tid («-m»). Kolonnen «Sr» er ren WA Combined Events.
- `nfif-masters-serietabell-menn.xlsx` / `-kvinner.xlsx`: bare øvelser som ikke finnes i mangekamptabellen.
  Seniorkolonnen er **ikke** lik senior-serietabellen på minfriidrettsstatistikk.info (se
  `docs/SERIETABELL_SAMMENLIGNING_2026-09-26.md`).
