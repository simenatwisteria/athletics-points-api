# Parameterdata

Parameter-JSON generert fra `sources/` av skriptene i `scripts/` (f.eks. `tyrving_parameters_2014.json` fra
`extract_tyrving_params.py`). Redigeres aldri for hånd.

Unntak: `event_catalog.json` (AP-021) er håndskrevet katalogdata, ikke parametre: engelsk navn og menygruppe
per `event_id`. En test sjekker at den dekker alle øvelsene motorene tilbyr.
